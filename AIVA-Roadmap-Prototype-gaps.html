Build items 01–06 closed eight roadmap capabilities outright and advanced one. Two of them — the registry, and gap detection — came along as a consequence of the rule that every persona must be able to demo everything; one hard-wired scenario wouldn't satisfy it.

02 / DEMO BY PERSONA

Any one person can demo every capability, from any persona

Each persona's four welcome chips are deliberately one of each kind: a grounded answer, a clarifying question, an invoked AI experience, and a pointing question. Switch persona, click the four chips in order, and the capability set has been shown. Say clear between runs — session memory will otherwise skip the clarifying question the second time, which is itself worth showing.
